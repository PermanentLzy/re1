💡 QUICK TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 使用 -opt 参数启用所有优化:
   ✓ 推荐: mycompiler code.src -opt
   ✗ 不推荐: mycompiler code.src (没有优化)

2. 查看生成的汇编代码:
   mycompiler code.src -opt > output.s
   cat output.s

3. 对比优化前后的 IR:
   set DEBUG_IR=1
   mycompiler code.src > ir_before.txt
   mycompiler code.src -opt > ir_after.txt
   diff ir_before.txt ir_after.txt

4. 测试特定优化的效果:
   编辑 src/optimizer/Optimizer.cpp
   注释掉特定的 pass() 调用
   重新编译并对比性能

5. 如果性能下降:
   • 检查是否使用了 -opt 参数
   • 运行 ctest 确保功能正确
   • 查看 DEBUG_OPTIMIZER 输出检查优化过程

❓ 常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 编译失败说找不到某些文件？
A: 运行: cd build && rm -r * 
   然后: cmake .. && cmake --build . -j4

Q: 优化后代码变得更大了？
A: 检查是否真的使用了 -opt 参数
   运行: echo "int f() { int x = 1; }" | mycompiler -opt

Q: 优化效果不明显？
A: 依赖源代码的结构。如果代码中没有循环或乘法，效果会更小。
   试试 test07_while.src 或 test22_mod_div.src 看效果。

Q: 我想只启用某些优化？
A: 编辑 src/optimizer/Optimizer.cpp 的 optimize() 函数，
   注释掉不需要的 pass 调用，然后重新编译。

    1️⃣  代码大小减少 (40 分)

        - 100% 通过 = 30 分
        - 50% 通过  = 15 分
        - 0% 通过   = 0 分

    总分 = 40 + 30 + 30 = 最多 100 分

❓ 如果出现问题?

问题: 找不到编译器
解决:
    cd MyCompiler
    rm -r build
    cmake -B build
    cmake --build build --config Release

问题: 性能得分很低
检查:
    1. 编译器是否存在: ls MyCompiler/build/Release/mycompiler.exe
    2. -opt 参数是否生效
    3. 查看详细输出: python performance_scorer.py --verbose

问题: Python 找不到
解决:
    1. 确保 Python 3 已安装
    2. 检查 Python 在 PATH 中: python --version
